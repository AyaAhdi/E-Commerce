# E-Commerce Static Website Template

A fully responsive, static e-commerce website template built with HTML, CSS, and JavaScript. 

## Features

- **Responsive Design**: Adapts beautifully to mobile, tablet, and desktop screens.
- **Comprehensive Pages**: Includes all essential e-commerce pages:
  - `index.html`: Home page with product highlights and carousels.
  - `shop.html`: Product listing catalog.
  - `details.html`: Single product detail view.
  - `cart.html`: Shopping cart management.
  - `checkout.html`: Checkout process page.
  - `wishlist.html`: Saved products list.
  - `compare.html`: Compare multiple products.
  - `accounts.html`: User account and profile dashboard.
  - `login-register.html`: Authentication forms.
- **Modern UI Components**: Utilizes FontAwesome for icons and Swiper.js for smooth touch-enabled carousels.

## Getting Started

Since this is a static website, no complex environment setup or build process is required.

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```
2. Navigate to the project folder.
3. Open `index.html` in your preferred web browser to view the site locally.

## Technologies Used

- **HTML5**: Semantic page structure.
- **CSS3**: Custom styling, animations, and responsive flexbox/grid layouts.
- **JavaScript (Vanilla)**: Interactive elements like mobile navigation and sliders.
- **FontAwesome**: Scalable vector iconography.
- **Swiper.js**: Touch-enabled sliders for product showcases.

## Project Structure

```text
├── assets/          # Contains CSS styles, JS scripts, and images
├── webfonts/        # Local font files for offline use
├── *.html           # All page templates (index, shop, cart, etc.)
└── README.md        # Project documentation
```

## Customization

To customize the website for your own brand:
1. Replace images in the `assets/img/` directory.
2. Update the color variables and styles in `assets/css/styles.css`.
3. Modify the HTML content in each page to fit your products and textual content.
